# sfx-gunshot

A single gunshot (0.9 s): a noise crack, a low falling boom and a filtered-noise tail. Synthesised by `../_tools/make_audio.py`, fixed random seed. **MIT**, Lumi Living, no samples.

`source.wav`: 44.1 kHz, 16-bit mono. The GoatTracker version is `../gt2-original/sfx-gunshot.ins` / `.bin`. Exercises: effect matching from a reference recording (E13).
