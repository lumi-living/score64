# sfx-clink

A metallic clink (0.7 s): four inharmonic partials (ratios 1, 2.76, 5.40, 8.93 over 2.3 kHz) with fast decays and a short noise strike. Synthesised by `../_tools/make_audio.py`, fixed random seed. **MIT**, Lumi Living, no samples.

`source.wav`: 44.1 kHz, 16-bit mono. The GoatTracker version is `../gt2-original/sfx-clink.ins` / `.bin`. Exercises: effect matching from a reference recording (E13).
