# sfx-clink

A metallic clink (0.35 s): a hard broadband strike, then ten inharmonic partials over 1.65 kHz that die within about 100 ms, plus a small rebound 45 ms later. A bell rings for seconds on a few partials; this does not. Synthesised by `../_tools/make_audio.py`, fixed random seed. **MIT**, Lumi Living, no samples.

`source.wav`: 44.1 kHz, 16-bit mono. The GoatTracker version is `../gt2-original/sfx-clink.ins` / `.bin`. Exercises: effect matching from a reference recording (E13).
