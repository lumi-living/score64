# sfx-footstep

A single footstep (0.4 s): heel then toe 70 ms apart, each a soft low thump with gravel crunch. The thump is kept quiet so the step doesn't sound like a drum. Synthesised by `../_tools/make_audio.py`, fixed random seed. **MIT**, Lumi Living, no samples.

`source.wav`: 44.1 kHz, 16-bit mono. The GoatTracker version is `../gt2-original/sfx-footstep.ins` / `.bin`. Exercises: effect matching from a reference recording (E13).
