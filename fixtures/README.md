# Fixtures

Rights-clear audio and MIDI with expected outputs. Each fixture is a folder:

```
fixtures/<name>/
  README.md        origin, licence (MIT-compatible only), what it exercises
  source.*         audio (WAV/FLAC) or MIDI
  expected/        snapshots and golden outputs, regenerated by tooling, never edited by hand
```

See [CONTRIBUTING.md](../CONTRIBUTING.md#audio-fixtures) for what is accepted.

## Current fixtures

All are Lumi Living's own work under MIT, generated by the scripts in [`_tools/`](_tools) from one shared score ("Sixteen Steps", [`_tools/composition.py`](_tools/composition.py)), with no samples or third-party recordings.

| Fixture | Kind | Generator |
|---|---|---|
| [`gt2-original`](gt2-original) | GoatTracker 2 song (2 subtunes), three sound-effect instruments | `make_song.py` (checked by `verify_song.sh`) |
| [`sparse-melody-bass`](sparse-melody-bass) | Audio + MIDI | `make_audio.py` |
| [`dense-mix`](dense-mix) | Audio + MIDI | `make_audio.py` |
| [`drum-loop`](drum-loop) | Audio + MIDI | `make_audio.py` |
| [`ambience-bed`](ambience-bed) | Audio | `make_audio.py` |
| [`sfx-footstep`](sfx-footstep), [`sfx-gunshot`](sfx-gunshot), [`sfx-clink`](sfx-clink) | Sound-effect references | `make_audio.py` |

Regenerate with `uv run fixtures/_tools/make_audio.py fixtures` and `python3 fixtures/_tools/make_song.py fixtures/gt2-original`. Both are deterministic; commit the regenerated files only if a generator changed on purpose.
